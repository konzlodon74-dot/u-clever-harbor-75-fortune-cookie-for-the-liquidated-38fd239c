A single fortune-cookie line for a crypto trader who has just been liquidated — funny, warm, and short enough to fit on a cookie slip.

Entry for the [make.fun bounty](https://make.fun/bounty/u-clever-harbor-75-fortune-cookie-for-the-liquidated-38fd239c).

## Run

```sh
python3 main.py
```

This writes the fortune line to `entry.txt` under `$MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline.
